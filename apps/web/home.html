questions.

Read the docs ↗
What can I use today?

The open-source engine and local setup guides are available. You’ll need to build from source. Hosted accounts and published npm/PyPI packages aren’t available yet.

Does it save every conversation?

No. Connecting an agent doesn’t automatically capture your chat history. The setup prompt adds project instructions for recalling context and saving meaningful updates. You control what belongs in the shared store.

Can I switch between agents?

Yes. Configure each supported MCP client separately against the same store. They can then recall saved project context. Our connection guide covers the setup.

What does it cost?

The engine is free, open-source software under Apache-2.0. You cover your own infrastructure and model-provider costs. See the pricing page for the proposed hosted rates.

How do I know it remembered correctly?

Check the source evidence, then verify a saved detail in a fresh session. The state walkthrough explains the difference between saving source notes and extracting structured facts.
