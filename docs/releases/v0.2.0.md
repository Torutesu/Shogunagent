# ShogunAgent v0.2.0

A local developer-preview release of the Rust memory engine, Linux binaries and container image. This release includes merged changes through PR #33; unfinished archive/restore and atomic ACL-audit work are excluded.

## Changes

- Enforce state mutation, export and provenance visibility under existing namespace ACLs. New correction/deletion suppression records are namespace-scoped; old evidence cannot recreate deleted work through consolidation.
- Retain GitHub issue/PR state changes and dated connector revisions, including small edits and `A → B → A` reversions. Exact-version replays remain idempotent; refetching can repair previously missed versions. Ordinary unversioned ingestion retains its existing near-duplicate policy.
- Improve lexical query relevance, preserve short/CJK query terms, apply upper-only time bounds before retrieval candidate limits, and avoid presenting old source quotes as proof of user-corrected wording.
- Add a source-checkout `connect --local` launcher and expose existing approval, audit and ACL reads through the Node read-only proxy. Approval decisions and access mutations remain outside that proxy.
- Expand deterministic typed-state acceptance coverage, source setup documentation, recorded Codex context-sharing evidence, and narrowly scoped secret-scanner regression coverage.
- Build container architectures on native runners with separate digest publication and a multi-platform index.

The Node launcher is available in the source checkout. This binary/container release does not publish npm or PyPI packages or deploy the website.

## Upgrade and limits

The store schema advances to V106. Before upgrading an existing store, stop writers and retain a verified encrypted backup. Do not open an upgraded store with v0.1.0; schema rollback is not a supported in-place operation. [V106 rollback guidance](https://github.com/Torutesu/Shogunagent/blob/v0.2.0/docs/migrations/V106-rollback.md) describes the recovery boundary. Historical suppressions without recoverable namespace information keep their original global effect.

Source timestamps govern retained connector chronology; missing timestamps retain ingestion-time fallback. Changed observations intentionally consume additional storage. Remote document deletion is not mirrored into local erasure. Existing `state.delete` remains irreversible; recoverable archive/restore is not included.

New acceptance tests use synthetic model/provider answers and synthetic vectors. They verify state transitions, filtering, storage and protocol behavior, not live extraction accuracy or semantic model quality. Earlier live-model and Codex source-sharing evidence covers narrower scenarios and older tested builds; this release does not claim fresh validation of every installed coding app. Local semantic embeddings still require an explicitly provisioned model and ONNX Runtime; otherwise retrieval uses the documented lexical path.
